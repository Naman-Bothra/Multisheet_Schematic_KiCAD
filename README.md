# Multisheet_Schematic_KiCAD
my first Multi sheet schematic in KiCAD
 Custom Arduino Uno Shield with L7805 Voltage Regulation & Status Indications

A professional, multi-sheet hierarchical hardware project designed in **KiCad E.D.A. 10.0.3**. This project implements an Arduino Uno-compatible expansion board featuring robust linear voltage regulation (`12V` down to `5V`), dedicated local power networks, and software-controlled LED diagnostic indicators.

---

## 🗺️ Project Architecture & Hierarchical Structure

The design follows a clean, modular multi-sheet schematic layout to maximize maintainability, isolate sub-circuits, and conform to industrial engineering standards.

```
Root (page 1)
 ├── J1 (12V Power Input Header)
 ├── J2 (5V Power Output Header)
 ├── Power (page 2)
 │    ├── Regulator (page 4): L7805 Linear Regulator Circuit
 │    └── Indications (page 5): Power & Diagnostic LED Array
 └── MCU (page 3): Arduino Uno R3 Footprint Interface
```

### 📄 Sheet Breakdown
1. **Root (Sheet 1):** Serves as the top-level block design interconnecting external input/output headers (`J1` for `12VIn` and `J2` for `5Vlocal`) with sub-sheets.
2. **Power (Sheet 2):** Intermediate bus routing layout connecting voltage processing directly with current-limiting diagnostic blocks.
3. **MCU Interface (Sheet 3):** Bridges the system connections to the **Arduino UNO R3** footprint. Features a clean, completely mapped pin configuration utilizing hierarchical labels.
4. **Regulator (Sheet 4):** Houses the **L7805 Linear Regulator (`U1`)**, input filtering capacitor (`C1`), and output smoothing capacitor (`C2`) alongside power-rail flags (`PWR_FLAG`).
5. **Indications (Sheet 5):** Features current-limiting resistors (`R1`, `R2`) driving two system LEDs (`D1` for constant `5V` power confirmation, `D2` for micro-controlled `MCULed` system heartbeat).

## ⚙️ Hardware Specifications & Net Mapping

### 🧩 Component Bill of Materials (BOM) Summary
| Designator | Component Name | Package / Footprint | Functional Description |
| :--- | :--- | :--- | :--- |
| **U1** | L7805 | TO-220 | +5V Linear Voltage Regulator |
| **A1** | Arduino_UNO_R3 | Standard Arduino Uno R3 Shield | Primary Processing Unit Interface |
| **C1** | Capacitor (C) | Surface-Mount / Through-Hole | Input Decoupling & Stability Ripple Filter |
| **C2** | Capacitor (C) | Surface-Mount / Through-Hole | Output High-Frequency Noise Filter |
| **R1, R2** | Resistor (R) | SMD/SMT | Current Limiting for Status Indicator LEDs |
| **D1** | LED | Standard Indicator | Constant Power Indicator (`5Vind`) |
| **D2** | LED | Standard Indicator | Microcontroller Status Indicator Pin `A0` (`MCULed`) |
| **J1, J2** | Conn_01x02_Pin | 1x02 2.54mm Pin Header | External Power & Signal Interconnect Junctions |

### ⚡ Critical Net Rail Configurations
* **`12Vin`**: High-voltage input channel feeding directly into Pin 1 (`IN`) of the L7805 regulator.
* **`5Vop` / `5Vlocal`**: Regulated quiet +5V output rail generated by Pin 3 (`OUT`) of the L7805, providing system power.
* **`5Vind`**: Dedicated status power bus running directly through current-limiting resistor `R1` to confirm active voltage regulation.
* **`MCULed`**: Targeted control net bound to Pin 9 (`A0`) of the Arduino Uno, enabling custom software-defined blink behaviors on LED `D2`.
* **`GND`**: Unbroken global ground distribution network shared across all functional blocks via specialized copper planes.

## 🎨 PCB Layout & Manufacturing Details

The physical board layout incorporates industrial design rules configured for 2-layer fabrication layout efficiency.

* **Layer Stackup:** 2-Layer Board (`F.Cu` Front Copper, `B.Cu` Bottom Copper).
* **Ground Strategy:** Dual-sided solid Ground planes (`GND`) configured on both the top and bottom layers to drastically reduce EM noise loop areas, maximize heat dissipation for the TO-220 package, and streamline trace routing.
* **Thermal Relief Design:** Set up with custom thermal relief connections (`0.5mm` gap clearances / `0.25mm` minimum width) on all ground-plane-connected pads to prevent cold-solder structural failures during assembly.
* **Trace Optimization:** Power routing features widened high-current traces to minimize impedance drops from the `12V` input to the regulation circuit.

## 🚀 Key Implementation & KiCad Settings Verified
* **ERC Clean Workflow:** Fully resolved initial reference designator conflicts (`#PWR?` duplicates) via programmatic schema annotations.
* **No-Net Island Prevention:** Cleanly avoided floating copper traps by mapping both copper zones to the global `GND` net layer, stabilizing high-frequency characteristics.
* **No-Connect Cleanliness:** All unused digital and analog pins on the `A1` microcontroller header explicitly utilize individual `No-Connect` cross-markers (`X`) to ensure predictable system behaviors.
